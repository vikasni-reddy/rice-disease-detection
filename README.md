🌾 Rice Disease Detection Using Deep Learning
📌 Overview

This project focuses on detecting common rice leaf diseases using a deep learning–based image classification approach. Rice diseases significantly impact crop yield, and early detection can help farmers take timely preventive measures.
The system classifies rice leaf images into multiple disease categories and provides predictions through a simple web interface.

🧠 Problem Statement

Manual identification of rice diseases is time-consuming, error-prone, and requires expert knowledge. This project aims to automate disease detection using computer vision and deep learning techniques to improve accuracy and accessibility.

🏗️ System Architecture

Image dataset preparation and preprocessing

Model training using a convolutional neural network

Model evaluation and validation

Web-based interface for real-time predictions

🦠 Disease Classes

Brown Spot

Leaf Blast

Leaf Scald

Sheath Blight

Healthy

⚙️ Technologies Used

Python

TensorFlow / Keras

OpenCV

NumPy, Pandas

Streamlit (for web interface)

📊 Model Highlights

Transfer learning–based CNN architecture

Data augmentation for improved generalization

Achieved high validation accuracy on test samples

Optimized for real-time inference

📁 Dataset Information

The dataset used in this project was compiled from multiple publicly available online sources for academic and learning purposes.

Due to the aggregated nature of the data and repository size constraints, the dataset is not included in this repository.

The dataset contains rice leaf images categorized into five classes as listed above.
This project primarily focuses on model design, training workflow, and end-to-end system integration rather than dataset creation.
