# Rice Fungal Disease Detection

## Overview
This project focuses on detecting common fungal diseases in rice crops
using an image classification pipeline.

## Problem Statement
Early identification of rice diseases helps prevent crop loss
and improves agricultural productivity.

## Project Structure
- Model training and evaluation
- Prediction pipeline
- Simple web-based interface for inference

## Key Learnings
- Data preprocessing for image-based systems
- Model evaluation and performance analysis
- Writing modular and maintainable code

## Tech Stack
Python, Machine Learning, Image Processing
